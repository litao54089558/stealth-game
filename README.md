Night Archive is a top-down stealth game: sneak past patrolling guards' vision cones, grab the keycards, and reach the green exit unseen.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome.
